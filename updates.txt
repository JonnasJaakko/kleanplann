KleanPlann — изменения в этой сборке

1. image_processor.py полностью переписан.
   - выделяются толстые тёмные архитектурные стены;
   - насыщенные зелёные/цветные элементы эвакуации не используются как стены;
   - дверные проёмы закрываются по осевым разрывам стен;
   - дуги открывания двери не требуются для закрытия контура;
   - помещения ищутся как замкнутые свободные области;
   - группы повторяющихся мелких параллельных линий распознаются как лестницы;
   - добавлена эвристическая классификация коридоров, санузлов и других помещений;
   - detect_walls() сохранён для совместимости.

2. Автоопределение типов комнат добавлено отдельной кнопкой под авторасчётом персонала.
   Для реальной площади используется правило: помещение < 10 м², расположенное рядом с коридором, может быть санузлом.

3. Нормативы:
   - лестница: коэффициент сложности 1.0;
   - лестница: 3 уборки в день;
   - добавлена проходимость по умолчанию в таблицу нормативов.

4. Таблица комнат:
   - добавлен редактируемый столбец «Проходимость»;
   - обычный ЛКМ по строке открывает параметры комнаты;
   - назначение сотрудника из редактора удалено: оно выполняется на экране ответственности.

5. Экран ответственности:
   - рабочее колесо мыши масштабирует план;
   - ПКМ + перетаскивание панорамирует;
   - SHIFT + наведение подсвечивает комнаты того же сотрудника;
   - режим исключения: зелёный = включено, красный = исключено; ЛКМ переключает состояние;
   - исправлено падение при «Готово»;
   - multi-floor зоны используют floor_index и не путают одинаковые номера комнат.

6. Scheduler:
   - проверена работа с несколькими этажами и одинаковыми номерами комнат;
   - зоны ответственности являются жёстким ограничением для назначений;
   - сверхурочная задача ставится сразу после последней работы сотрудника;
   - для сверхурочной задачи cooldown помещения не применяется.

7. Отчёт:
   - после «Конец» добавлена продолжительность в минутах;
   - тип помещения отдельным столбцом;
   - сверхурочные строки светло-красные;
   - floor-aware поиск комнат.

8. DOCX:
   - все секции горизонтальные;
   - таблицы расписания содержат отдельный столбец типа помещения;
   - multi-floor зоны корректно разделяются по этажам.
